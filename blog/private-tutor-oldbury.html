Check understanding when the layout changes

Check whether a skill survives a different layout

A pupil may succeed on a familiar worksheet because the layout tells them which method to use. A change in presentation can reveal whether the underlying idea is secure.

A practical example

After practising fraction equivalence in a table, show the same relationship as a shaded diagram or a missing-number statement. Ask the learner to explain what stayed the same and what changed.

Keep the mathematics at the same level so the new layout is the main difference. If the pupil struggles, connect the representations rather than simply adding more questions in the original format. Use the attempt to plan a lesson with the current team, confirming the actual location and availability for Oldbury families.

Test a skill with unfamiliar wording but familiar content

After a pupil succeeds with “find one quarter of 28”, ask “28 counters are shared equally between four trays; how many go on each tray?” Compare the two tasks and identify the same mathematical structure.

If one wording causes difficulty, discuss the language before adding harder numbers. A new context should not secretly add several new skills at once. This gives the tutor clearer evidence about transfer and helps the family avoid mistaking a wording problem for a complete loss of mathematical understanding.
